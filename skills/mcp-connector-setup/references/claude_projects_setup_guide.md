# Claude Projects & Daily Automation SOP Guide

Based on the 1-Hour Claude Full Course workflow, this guide shows how to turn recurring tasks into reusable **Claude Projects**, **Skills**, and **Bookmark Shortcuts**.

---

## 1. The 5 Core Claude Projects to Create

Every Claude Project has three pillars:
1. **Instructions** — Your persistent super-prompt (Claude adheres closely to detailed multi-step instructions).
2. **Files** — Reference knowledge (top-performing tweets, past blog posts, brand/CTA context, GitHub/Google Drive files).
3. **Memory** — Auto-learned preferences that evolve across chats inside the project.

| # | Project Name | Attached Knowledge Files | Bookmark Label |
|---|---|---|---|
| 1 | **SEO Writing Project** | 3–5 best past blog posts + Brand/CTA context doc | `Claude Project - SEO Writer` |
| 2 | **X Greatest Hits Rewriter** | Top 10% winning tweets + Bottom 90% hooks to avoid | `Claude Project - X Viral` |
| 3 | **Live Stream Mega-Guide** | Offer stack doc + Hook-Story-Offer template | `Claude Project - Livestream` |
| 4 | **YouTube Titles Engine** | Top 10% channel titles + Bottom 90% low-CTR titles | `Claude Project - YT Titles` |
| 5 | **LTO Promo Campaigner** | Product/service offers + bonus templates | `Claude Project - LTO Promos` |

> **Speed Tip:** Skip writing long project descriptions—focus your effort on crisp **Instructions** and high-signal **Knowledge Files**, then **bookmark each project URL** in your browser bar for instant 1-second recall.

---

## 2. Projects vs. Skills (`SKILL.md`) — When to Use Which

- **Use a Claude Project** when you have a dedicated workspace with persistent project files, ongoing chat history, and isolated project memory.
- **Use a Claude Skill (`SKILL.md`)** (Settings -> Capabilities -> Skills) when you want to invoke a repeatable workflow **inside any chat** without switching tabs (e.g., *"Use the youtube-title-generator skill for [Topic]"*).
- **Convert Any Good Chat Into a Skill**: After refining a workflow in chat, prompt: *"Save this workflow as a skill called [skill-name]"* -> Copy to Your Skills -> Export/share the generated `SKILL.md`.

## 3. Operational Power Tips from the Course

1. **Extended Thinking Toggle**:
   - Keep **OFF** by default for fast daily drafting and to preserve session/weekly usage credits.
   - Toggle **ON** for complex coding, architecture, or high-stakes multi-step reasoning.
2. **Screenshot-to-Spreadsheet Recreation**:
   - Take a screenshot of any table or tracker -> Paste into Claude -> Prompt: *"Recreate this spreadsheet"* -> Click **Open in Drive** to generate a native Google Sheet instantly.
3. **Clean Copy-Paste Formatting**:
   - Wait for Claude to finish generating before copying (avoid copying mid-stream).
   - Paste using **`Cmd + Shift + V`** (Mac) or **`Ctrl + Shift + V`** (Windows) to avoid broken paragraph formatting on X or LinkedIn.
4. **Content Engine Stack (Top 3 Tools)**:
   - **Claude** (scripts, SEO blogs, X posts, mini-apps, 30-day trackers)
   - **ElevenLabs** (AI voiceover)
   - **HeyGen** (AI avatar videos)
